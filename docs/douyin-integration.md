# 抖音员工闭环接入说明

## 本次实现的交互

- 账号授权：同一后台发起抖音与来客授权；当前官方按钮为待接入。支持显式选择本地示例授权、门店范围、能力及撤销。
- 需求优先：一句话预填创作目标、受众、主题、规格、配音字幕、配乐、结尾引导、必须保留和不要出现的内容；客户编辑并确认。当前是确定性规则预填，非已接入大模型。
- 视频预览与发布：3个素材后确认简报；可体验交付示意或导入本地视频播放器。浏览器读取文件后才允许确认；修改方案或素材使成片确认失效。
- 发布任务：仅列当前企业、当前门店有发布示例授权的账号，以及对应来客授权的在售商品。变更内容/目标/授权须重新预览确认；重复保存同一版本不重复建任务。真实发布按钮始终不可用。
- 日报：按当前示例授权展示订单、退款和验券；通用直播数据已下线，网站视频指标与油站评价待核验，均无数值且不开放授权。缺数为 null，不当作0。时间按 Asia/Shanghai，默认昨天。
- 自动推送：保存每日时间、渠道、门店与当前企业接收范围的配置草案；未启动调度。工作台、飞书、企微均需未来后端接入。
- 直播：合法抖音链接或room_id、自动回扫禁用、无证据待核验；示例结果独立标注，不冒充输入直播间的实际结果。

## 真实上线需要接入的服务

| 领域 | 所需后端职责 | 当前状态 |
| --- | --- | --- |
| 网站应用 | 应用上线、发布能力申请、账号OAuth起始与回调、凭证刷新与撤销 | 无凭证，无OAuth请求 |
| 来客应用 | 商家业务授权、实际可见门店/商品、订单及验券记录；油站评价不默认支持 | 无凭证，无业务请求 |
| 生成 | 安全文件上传、素材识别、活动资料核对、方案版本确认、异步视频生成、成片审查 | 规则简报及示意交付 |
| 发布 | 账号与POI资质验证、用户确认版本、获批后上传创建作品、幂等及结果跟踪；商品仅选品参考 | 本地示例任务 |
| 日报 | 依授权读取各源、异步补数、明确增量/累计和归因、收件人权限校验、调度及消息渠道连接 | 本地示例和配置草案 |
| 直播素材诊断 | 由商家提供有权使用的录屏/截图、时间戳与规则版本，人工辅助复核；无已确认的官方采集路线，禁止自动抓流 | 链接登记与示例结果，自动回扫禁用 |

正式接口可以由本后台统一发起，账号持有人仍应在官方授权页面完成登录和同意；不能在本页面收集账号密码。两个应用的凭证不得混用。应用获批能力与客户授权范围分别检查。

localStorage 仅存演示授权和配置，任何人可修改，不能作为生产权限依据。生产服务端根据登录租户查找绑定账号、门店和商品，拒绝客户端自由传递其他租户的ID；每次执行时重新校验scope、有效期及撤销状态。敏感凭证放服务端加密存储，不进入浏览器、下载文件或日志。

发布前冻结内容版本、成片标识、标题、账号、POI、商品和授权版本；任何变化需重新确认。服务端使用任务幂等键，失败与审核中状态独立，只有获取可靠平台结果后才展示已发布。

## POI 与商品挂载

2026-10-24查阅的创建视频文档支持 `poi_id` 及POI门店推广参数，不能据此断定任意原生团购商品URL可作为视频锚点同时挂载。当前原型保留业务选择并阻断真实发布，不生成虚假的商品链接。当前只能保存选品参考，不能把商品作为待执行挂载参数。若未来官方明确开放，再用实际应用权限、目标行业/商品/账号核验完整发布路径；不支持时需向用户明确可选发布方式，不悄悄丢弃商品。

## 直播规则

当前四维24项由本地 `douyin-live-room-review` 技能整理为内部诊断清单。720p、文字占比、开播时长、双主播等不能在缺少现行官方条文时作为自动处罚阈值。

本次检索找到生活服务学习中心和抖音直播行为规范，但未获取到可确认的最新完整规则版本，因此页面明确“官方最新完整版本尚待同步核验”。接入后应保存规则标题、来源URL、发布时间、生效时间、适用行业、核验人及版本；变更须复核。静态画面不能推断主播声音、总时长、投流或引流行为，未知项标需核验。任何建议不代表抖音平台裁定。

## 验证

`node tests/douyin-flow.test.cjs` 覆盖权限范围、过期撤销、跨租户资源、商品在售、确认失效和幂等、日报缺数、链接验证与证据不足；`node tests/private-flow.test.cjs` 验证私域流程未回归。

最新边界浏览器验证：直播/视频指标授权项不可选；来客油站评价不可选；旧浏览器示例授权不会恢复这些能力；日报直播/视频没有数值；自动回扫与频率不可操作；390px授权弹窗无横向溢出。原有需求预填、确认失效、幂等、跨企业隔离由业务回归测试覆盖。
