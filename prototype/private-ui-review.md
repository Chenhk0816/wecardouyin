# 私域工作空间更新与验证

## 依据与范围

依据用户提供的客户群发、统计查询、群聊查询和运营 QA 目录四份 Skill。它们用于设计业务流程，不授权执行真实业务命令。

移除协作任务、最近协作、联合营销对话及其验收区。首页改为员工能力入口，视频页返回今日工作台。原深绿配色、侧栏与三栏布局保留；抖音视频流程保持可访问。

## 私域模块

1. 客户群发：选择企业与员工；客户范围、条件关系、会员号名单及排除标签；文本/图片/链接/小程序、发送安排；匹配预览、显式确认与保存本地草案。允许查看或取消本地草案，不能真实发送。
2. 运营统计：总览、员工/油站/渠道排行、留存入口、群聊统计、两种群发的统计与接收/员工明细。已发送不等于已送达，未发送与未触达不能直接相加。留存定义缺失时不生成数值。
3. 群聊查询：企业、群名、群主、分组，分页及群详情/成员只读弹窗。
4. 运营问答：15 章目录，245 条正文未提供。有限业务文档摘要包含来源；缺少正文的问答显示缺失提示。

附件对频次限制存在不同描述，页面提示由企业实际配置和业务服务核实，不宣称固定平台上限。
